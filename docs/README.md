# Documentation

| Path | Contents |
|------|----------|
| `docs/*.md` | Living operational guides, architecture, methodology, and product domain references (kept at stable paths referenced by code, OpenAPI schemas, Dockerfiles, and CI). |
| [`docs/research/`](research/) | Background research papers, methodology benchmarks, and empirical experiment reports. |
| [`docs/reviews/`](reviews/) | Point-in-time architecture reviews, playbook gap reviews, and streamlining proposals. |

| [`docs/superpowers/archive/`](superpowers/archive/) | Archived implementation plans (`plans/`) and older specifications (`specs/`). |
| [`docs/transition_barrier/`](transition_barrier/) | Transition Barrier Assessment rule book (`RULE_BOOK.md`, checked by tests) and source workbooks. |
| [`docs/adr/`](adr/) | Architecture Decision Records (`0001-*.md`). |
| [`docs/brand/`](brand/) | Pixel A mark and ARP lockup SVGs (governed by [`BRAND.md`](BRAND.md)). |
| [`docs/golden_drafts/`](golden_drafts/), [`docs/samples/`](samples/), [`docs/scale/`](scale/), [`docs/decks/`](decks/), [`docs/screenshots/`](screenshots/) | Reference empirical drafts, XBRL sample outputs, scale test results, house-style deck PDF, and UI screenshots. |
